# Flora Store Launch

Please implement the following complete updates and features based on my client's requirements for this skincare e-commerce store:



1. Store Branding & Currency:

- Name the store "Flora Store" (فلورا ستور).

- Change the store currency to Egyptian Pounds (EGP / ج.م) instead of USD.



2. Color Palette & Aesthetics:

- Apply a clean, professional, and elegant aesthetic suitable for a premium skincare brand.

- Use a soft, modern color palette consisting of Earthy Nudes, Soft Rose, Creamy White, and Dark Charcoal for text to maintain high readability and a luxurious look.



3. Multi-language Support (English & Arabic):

- Make the website fully bilingual, supporting both English and Arabic.

- Add a language switcher toggle in the navigation bar.



4. Brand Categorization & Filter (By Name, Not Letters):

- Create a feature to organize and filter products directly by brand name (e.g., CeraVe, The Ordinary, Vichy). Do NOT use alphabetical filters (like A, B, C).

- When a user clicks on a specific brand name, only that brand's products should display.



5. Enhanced Product Details Page:

- Add a section under each product for "Product Benefits" (الفوائد).

- Display a clear discounted price alongside the original price (strikethrough) if a sale is active.

- Add a dynamic availability badge on each product indicating if it is "Instant Shipping" (شحن فوري) OR "Pre-Order: Arrives in 15-20 days" (طلب مسبق: يصل خلال ١٥-٢٠ يوم).



6. Full Admin Control Panel (Product Management):

- Create a secure Admin Dashboard where the store owner can easily add new products, delete existing ones, and edit product details (including names, descriptions, images, benefits, availability status, and prices).



7. Custom Checkout & 50% Deposit via WhatsApp:

- In the final checkout step, after the user fills in their shipping details (Name, Address, Phone Number), display this instruction: "To confirm your order, please transfer a 50% deposit via Vodafone Cash to our number and send the transfer screenshot."

- When they click "Confirm Order", it must automatically redirect them to the store's WhatsApp with a pre-filled message containing all order details, the total, the required 50% deposit amount, and a prompt to attach their payment screenshot.
